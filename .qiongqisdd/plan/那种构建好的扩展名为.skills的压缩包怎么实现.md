## `.skills` 压缩包方案

### 定义

> `.skills` 是一个 **zip 格式**的压缩包（扩展名 `.skills`），包含一个完整技能包的所有文件。用户拿到一个文件即可安装。

### 内部结构

```
kk-business-query.skills        ← zip 文件
├── SKILL.md                    ← 包清单（元数据 + 指南）
├── install.sh                  ← 安装脚本
├── uninstall.sh                ← 卸载脚本
├── CHANGELOG.md                ← 版本记录
├── requirements.txt            ← Python 依赖
├── scripts/cli.py              ← 可执行代码
├── references/                 ← 参考文档
├── LICENSE.txt                 ← 许可证
└── .skills.json                ← 构建元数据（自动生成）
```

### 构建流程

```
技能目录（开发态）          构建                分发态
                         
kk-business-query/      ──→   kk-business-query.skills
├── SKILL.md                    (zip 压缩包，~50KB)
├── scripts/
├── references/
└── ...
```

### 实现方式

需要 3 个工具脚本：

```yaml
scripts/
├── build-skills.py      # 技能打包器
├── install-skills.py     # 技能安装器
└── list-skills.py        # 技能清单查看
```

---

### 工具设计

#### 1. `build-skills.py` — 打包器

```bash
# 打包单个技能
python3 scripts/build-skills.py stock/kk-business-query
# 输出: dist/kk-business-query.skills

# 打包所有带代码的技能
python3 scripts/build-skills.py --all

# 打包时指定版本
python3 scripts/build-skills.py stock/kk-business-query --version 1.2.0
```

**打包过程：**
1. 读取 `SKILL.md` 的 frontmatter 验证合法性
2. 生成 `.skills.json`（含构建时间、version、文件列表 hash）
3. 整个目录 zip 压缩 → `dist/<name>-<version>.skills`
4. 同时生成 `dist/index.json`（所有包的注册索引）

#### 2. `install-skills.py` — 安装器

```bash
# 从 .skills 文件安装
python3 scripts/install-skills.py dist/kk-business-query.skills

# 安装到指定目录
python3 scripts/install-skills.py dist/kk-business-query.skills --prefix ~/.kskills

# 查看包内容但不安装
python3 scripts/install-skills.py dist/kk-business-query.skills --list

# 校验包完整性
python3 scripts/install-skills.py dist/kk-business-query.skills --verify
```

**安装过程：**
1. 解压到目标目录（默认 `~/.kskills/<name>/`）
2. 校验 SKILL.md 合法性
3. 如果有 `install.sh`，询问用户是否执行（安装 Python 包等）
4. 如果有所需环境变量（如 `IWENCAI_API_KEY`），检查是否已设置
5. 写入安装清单到 `~/.kskills/.registry.json` 便于卸载

#### 3. `list-skills.py` — 查看已安装的技能

```bash
# 列出所有已安装的技能
python3 scripts/list-skills.py

# 查看特定技能详情
python3 scripts/list-skills.py kk-business-query
```

---

### 按技能类型区别对待

| 类型 | `.skills` 包含 | 安装复杂度 |
|------|---------------|-----------|
| **knowledge-only**（coding/） | 仅 SKILL.md + CHANGELOG.md | 解压即可 |
| **Python 有代码**（stock/） | 全量 + requirements.txt | 解压 + `pip install` 依赖 |
| **Node.js**（chart-visualization） | 全量 + package.json | 解压 + `npm install` |

### 完整工具链工作流

```
开发态                                           分发态
                    build-skills.py
skill/ ──────────────────────────────────→  dist/<name>.skills
                                                ↓
                                          GitHub Releases / 网页下载
                                                ↓
                    install-skills.py
                                          ~/.kskills/<name>/
                                                ↓
                                          Agent 平台读取 SKILL.md
```
