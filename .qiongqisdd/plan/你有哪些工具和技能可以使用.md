## 🛠 可用工具（Tool Set）

### 内置工具

| 工具 | 用途 |
|------|------|
| **read** | 读取文件内容（支持 offset/limit 分段） |
| **write** | 创建/覆写文件 |
| **edit** | 精准编辑文件（基于原文替换，支持多段同时修改） |
| **grep** | 文件内容搜索（支持正则、忽略大小写、上下文） |
| **find** | 按 glob 模式搜索文件 |
| **ls** | 列出目录内容 |
| **bash** | 执行任意 shell 命令（支持长会话） |
| **web_fetch** | 抓取 HTTP(S) URL 内容 |
| **web_search** | 搜索引擎查询 |
| **echo** | 回显文本 |

### 记忆工具

| 工具 | 用途 |
|------|------|
| **memory_create** | 创建长期记忆（需用户批准） |
| **memory_update** | 更新/禁用已有记忆 |
| **memory_delete** | 删除记忆 |

### MCP 外部工具

| 工具 | 用途 |
|------|------|
| **web_search_prime** | 高级网页搜索（可限定地域/时效/域名） |
| **web_reader** | 深度网页读取（支持 GFM、图片摘要、链接摘要） |
| **analyze_image** | 通用图像分析 |
| **analyze_data_visualization** | 图表/仪表盘分析 |
| **analyze_video** | 视频内容分析 |
| **extract_text_from_screenshot** | 截图文字提取（OCR） |
| **ui_diff_check** | 两个 UI 截图对比 |
| **ui_to_artifact** | UI 截图 → 代码 / 提示词 / 设计规格 |
| **diagnose_error_screenshot** | 错误截图诊断 |
| **understand_technical_diagram** | 技术架构图/流程图分析 |

### 计划与进度工具

| 工具 | 用途 |
|------|------|
| **create_plan** | 创建/更新实现计划 |
| **todo_list** | 查看当前任务列表 |
| **todo_write** | 更新任务进度 |
| **request_user_input** | 向用户提问并等待回答 |
